# ProvenanceTag

De dónde viene un dato y cuándo se vio (principio III). Va al pie de toda tarea y de todo dato derivado.

- `source`: `relay` (cian), `git` (azul), `github` (naranja) o `declarado` (violeta, con fondo `declared-soft` y `by` con quién lo declaró).
- `stale` lo apaga a `state-stale` con trazo discontinuo y añade la palabra «viejo». Un dato viejo nunca se pinta con el color de su fuente.

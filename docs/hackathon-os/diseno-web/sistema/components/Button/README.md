# Button

Botón de acción de la web de trabajo (reclamar, anotar, confirmar, publicar).

- `primary` (contorno `relay` con fondo `relay-soft`) para la acción principal de una tarjeta; `solid` solo para la única acción principal de una vista; `ghost` para lo demás; `danger` para descartar.
- `busy` mientras el demonio local ejecuta la acción; el botón no se pulsa dos veces.
- Cada botón dispara un comando ya comprobado del demonio. Nunca un campo de texto libre que acabe en una orden.
